# DevSecOps Dojo v0.2.1 : charte graphique générique v2.1

Cette version ne change aucune fonction : elle habille l'interface de la v0.2 avec la charte graphique
générique v2.1 (dépôt `Aliquanto3/charte-generique`). Toujours hors ligne, sans télémétrie.

## Contenu

- **Jetons** : `tokens.css` porte les valeurs de la charte, choisies par usage (texte, aplat, trait,
  statut). Sombre d'abord ; le clair suit le système (`prefers-color-scheme: light`) ou
  `data-theme="light"` ; `data-theme="dark"` force le sombre. Le terminal reste sombre dans les deux thèmes.
- **Boutons** : principal neutre (`bouton`, `sur-bouton`, `bouton-survol`), jamais un aplat bleu, y
  compris les boutons à bascule ; secondaire en contour `trait-fort` ; focus `focus`.
- **Catégories** : les quatre couleurs de disciplines passent sur les séries `cat-1`, `cat-3`, `cat-4` ;
  les fonds doux de catégorie sont `primaire-doux`, `succes-doux` ou `surface-alt`.
- **Signature** : filet or sous le titre de la page, pictogramme et favicon de la charte.
- **Polices** : Sora 600 (titres), Atkinson Hyperlegible (texte), JetBrains Mono (code), avec les piles de
  repli de la charte. Fredoka et sa licence sont retirées ; la licence OFL de Sora est jointe.
- **Rapport HTML exporté** : même palette (sombre, clair, impression), titres en Sora, filet or.
- **Tests** : `tests/test_charte.py` (contrastes 4,5:1 du texte et 3:1 des marques dans les deux
  thèmes, aucun hex hors `tokens.css`, aucun aplat bleu de bouton, polices, favicon) ; tests de
  jetons et de contraste existants réalignés.
- **Captures** : `docs/media/charte-v2/` (catalogue clair et sombre, diagnostic sombre).

## Limites

- **Pas de sélecteur de thème** dans l'interface : le thème suit le système. À reprendre dans une story.
- **Historique non migré** : `docs/recette/*.html`, `docs/forge/*.html`, `_bmad-output/` (dont les
  maquettes et `DESIGN.md`), `.claude/`, et les notes des versions précédentes gardent l'ancienne charte.
- **Captures partielles** : seules les pages Catalogue (deux thèmes) et Diagnostic (sombre) sont
  captées ; l'accès exige le jeton de session, ce qui a empêché les autres pages en navigateur sans tête.
- **Numérotation** : le jalon « v0.3 » (station 4, livraison) annoncé dans le README n'est pas livré par
  cette version, qui ne porte que la charte.
- **Graisses** : Sora n'est fournie qu'en 600 et Atkinson en 400 et 700 ; les graisses intermédiaires
  sont approchées par le navigateur.
- **Pas de liens soulignés dans la navigation** (liens de navigation, repérés par la ligne sous la page
  courante) ; les liens du texte courant restent soulignés.
